This PR prepares dotfiles for Caelestia Shell to be owned and installed by Gentoo/Portage (via `arrans_overlay`) rather than cloned as a git repository by `chezmoi`.

**Note:** The Caelestia Gentoo package (e.g., `gui-apps/caelestia-shell`) should be installed via Portage before applying or merging this migration.

### Changes
* **Removed:** The Caelestia Shell git repository checkout previously managed by `chezmoi` via `.chezmoiexternal.toml`.
* **Portage Ownership:** Caelestia Shell application and CLI binaries will now be system-installed by Gentoo Portage.
* **Dotfiles Ownership:** All personal Hyprland configurations (`hyprland_features = "quickshell"`, keybinds calling `caelestia shell -d`) remain safely managed by dotfiles.
* **Removal Mechanism:** Added `.chezmoiremove` (for general path tracking) and a specific `run_once_remove_quickshell.sh.tmpl` script. `chezmoi` conservatively protects `.git` directories during removal, so the script explicitly ensures the old `~/.config/quickshell` checkout is fully purged and doesn't shadow the new system install.
* **Testing:** Ran `chezmoi apply --dry-run` and locally validated that the old checkout structure and `.git` objects are successfully deleted without affecting unrelated configurations.
